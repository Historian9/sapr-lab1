Автор: Борода Д.А.
Группа: М3О-407Б-23

## Описание

Простой консольный калькулятор на Python (`calc.py`).

Поддерживаемые операции:
- `fact N` — факториал числа N
- `fib N` — N-е число Фибоначчи
- `gcd A B` — наибольший общий делитель чисел A и B

## История изменений

- Добавлена операция `fib` (числа Фибоначчи).
- Добавлена операция `gcd` (НОД), калькулятор принимает несколько аргументов.

## Запуск

```
python3 calc.py fact 5      # 120
python3 calc.py fib 10      # 55
python3 calc.py gcd 12 18   # 6
python3 -m unittest -v      # автотесты
```

# Часть 2. Проектирование в САПР Quartus II (папка `altera/`)

Вариант 3: распределитель сигналов на базе **счётчика Джонсона**,
последовательность `y = 2,2,1,3,2,3,1,3,…`, синхросигнал `C` — кнопка `KEY[3]`,
выходы — светодиоды `LEDG[1..3]`, плата **DE1** (Cyclone II EP2C20F484C7).

| Файл | Назначение |
|---|---|
| `johnson4.v` | блок 1: 4-разрядный счётчик Джонсона (8 состояний) |
| `rsp.v` | блок 2: распределитель сигналов (минимизированные функции) |
| `lab1_v3.bdf` | схема верхнего уровня (top-level entity в Quartus) |
| `lab1_v3_top.v` | текстовый аналог схемы, для моделирования |
| `lab1_v3.qpf`, `lab1_v3.qsf` | проект Quartus, привязка выводов |
| `lab1_v3.sdc` | временные ограничения |
| `sim/` | тестбенч и скрипт моделирования (Icarus Verilog) |
| `build.bat` | компиляция из командной строки |

Привязка выводов: `C` → KEY[3] (PIN_T21), `Y[0]` → LEDG[1] (PIN_U21),
`Y[1]` → LEDG[2] (PIN_V22), `Y[2]` → LEDG[3] (PIN_V21).

Моделирование: `altera/sim/run_sim.sh` (нужен `iverilog`).
