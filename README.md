## Описание

Простой консольный калькулятор на Python (`calc.py`).

Поддерживаемые операции:
- `fact N` — факториал числа N
- `fib N` — N-е число Фибоначчи
- `gcd A B` — наибольший общий делитель чисел A и B

## История изменений

- Добавлена операция `fib` (числа Фибоначчи).
- Добавлена операция `gcd` (НОД), калькулятор принимает несколько аргументов.

## Запуск

```
python3 calc.py fact 5      # 120
python3 calc.py fib 10      # 55
python3 calc.py gcd 12 18   # 6
python3 -m unittest -v      # автотесты
```
